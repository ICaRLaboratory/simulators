제어 구조

그림에 초점을 맞춘 뒤 방향키로 좌우로 스크롤하세요.

모델·제어식·단위·실험 범위

모델과 제어식

M(q)q̈ + C(q,q̇) + G(q) = τ

M₁₁ = 16/15 + 0.64 cos(q₂), M₁₂ = M₂₁ = 16/75 + 0.32 cos(q₂), M₂₂ = 16/75

h = −0.32 sin(q₂); C = [h(2q̇₁q̇₂+q̇₂²), −h q̇₁²]

G = 9.81[1.2 cos(q₁)+0.4 cos(q₁+q₂), 0.4 cos(q₁+q₂)]

τᵢ = sat(Kpᵢ(qᵣᵢ−qᵢ) + KiᵢIᵢ − Kdᵢq̇ᵢ + Gᵢ)

실험 범위와 단위

수직 평면의 균일한 0.8 m, 1 kg 링크 두 개입니다. q₁은 수평 기준, q₂는 상대 관절각이며 반시계 방향이 양수입니다.

두 PID는 같은 결합 관성·코리올리·중력을 공유합니다. D는 측정 각속도에 작용합니다.

제어 토크를 최대 5 ms 동안 유지하는 RK4입니다. 포화 방향의 적분을 멈추고 Ki=0이면 적분 기억을 지웁니다.

마찰과 충돌 모델은 제외합니다. |q|≥2.8 rad이면 안전 정지합니다.

고정 계산 간격 0.005 s. 숨겨진 탭은 일시정지합니다.
