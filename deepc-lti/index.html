2차 LTI 시스템의 데이터 기반 예측 제어(DeePC)

같은 시스템에 서로 다른 입력을 가해 기록한 데이터로 다음 입력을 결정합니다. 입력을 한 값으로 고정하면 무엇을 예측할 수 없게 될까요?

2차 시스템 설정

G(s) = 1 / (s² + s + 1)

데이터로 제어한 계단응답

출력 y목표 r

제어기 설정

10
0.2

학습에 사용한 입출력 기록

기록 입력 u측정 출력 y

각 시각의 입력과 측정 출력을 함께 표시합니다. 이 기록은 위의 폐루프 응답과 별도로 수집합니다.

실험해 보기

데이터 수집 입력을 상수로 바꿔 보세요. 기록 길이는 같지만 입력 이력이 제공하는 독립적인 정보가 줄어듭니다. 변화하는 입력으로 돌아가 예측 구간을 바꿔 보세요.

적용 제어입력

적용 입력 u
종료 시 출력 y—
최대 적용 |u|—
입력 행켈 행렬 랭크 / 필요 랭크—
모델·제어식·가정

G(s) = b / (s² + a₁s + a₀),　b = Kωₙ²,　a₁ = 2ζωₙ,　a₀ = ωₙ²

[U_p; Y_p; U_f; Y_f] g = [u_p; y_p; u_f; ŷ_f]

J = Σ [(ŷ − 1)² + λ(u − uₛ)²]

무잡음 선형 시불변 시스템을 가정합니다. 시스템 설정을 변경하면 해당 시스템으로 데이터를 다시 수집합니다. 제어기는 전달함수 계수를 받지 않고 과거 입출력과 기록에서 만든 행켈 행렬로 미래 출력을 예측합니다. 데이터에서 구한 평형 입력 uₛ에서 벗어나는 양에 비용을 주고, 0.2초마다 첫 입력만 적용합니다. 입력 한계는 두지 않습니다.

같은 시스템으로 다른 제어 실험: PID → · MPC → · SMC → · TDC →
