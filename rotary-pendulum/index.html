모델·제어식·단위·실험 범위

모델과 제어식

q=[α,θ]; T=½(Jarm+mr²+ml²sin²θ)α̇²+mrl cosθ α̇θ̇+½ml²θ̇²; V=mgl cosθ

d/dt(∂T/∂q̇)−∂T/∂q+∂V/∂q=[τ−baα̇,−bpθ̇]

A=Jarm+mr²+ml²sin²θ; B=mrl cosθ; C=ml²; [A B; B C][α̈;θ̈]=[f;h]

f=τ−baα̇−2ml²sinθ cosθ α̇θ̇+mrl sinθ θ̇²; h=ml²sinθ cosθ α̇²+mgl sinθ−bpθ̇

τ=clamp(kα(α−αr)+kvα̇+kθθ+kωθ̇,−0.18,+0.18) N·m

실험 범위와 단위

m=0.12 kg, r=0.18 m, l=0.22 m, Jarm=0.004 kg·m², g=9.81 m/s², ba=0.012, bp=0.001 N·m·s/rad.

θ=0은 직립, +θ는 암의 +α 접선 방향으로 기울기입니다. 그림은 사시 투영입니다.

질량 없는 막대와 끝 질점, 점성 마찰. 모터 전기·막대 관성·스윙업 생략.

직립 선형화 극점 −2, −2.5, −3, −3.5 s⁻¹ 배치: 양의 이득 0.00470948, 0.01917211, 0.65593909, 0.06088376을 반올림.

최대 5 ms 토크 유지 RK4. |α|≥1.5 rad 또는 |θ|≥0.6 rad이면 실패를 유지합니다.

고정 계산 간격 0.005 s. 숨겨진 탭은 일시정지합니다.

  • 목표 암 각도: -0.6 … 0.6 rad
  • 암 위치 이득: 0 … 0.02 N·m/rad
  • 암 속도 이득: 0 … 0.06 N·m·s/rad
  • 진자 각도 이득: 0 … 1.2 N·m/rad
  • 진자 속도 이득: 0 … 0.15 N·m·s/rad
