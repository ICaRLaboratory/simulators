실험 설정

외란

누를 때마다 x 속도에 ‘속도 외란’ 설정값(m/s, 기본 0.15)을 더하고 y 속도에서는 뺍니다. 순간 속도 변화가 반복해서 누적되며 지속 힘은 아닙니다. 공의 x·y 위치와 판 기울기를 관찰하세요. 외란은 목표값과 별개로 시스템에 가하는 변화입니다. 설정과 작동 한계에 따라 복귀가 보장되지는 않습니다. 일시정지 중에는 시작을 눌러 이후 응답을 관찰하세요.

초기화하면 일시정지하며 설정은 유지됩니다.

모델을 불러오는 중입니다.

제어 구조

그림에 초점을 맞춘 뒤 방향키로 좌우로 스크롤하세요.

모델·제어식·단위·실험 범위

모델과 제어식

βx=clamp⁡(kpx(xr−x)−kdxvx,−βmax⁡,+βmax⁡); βy=clamp⁡(kpy(yr−y)−kdyvy,−βmax⁡,+βmax⁡)

x˙=vx; v˙x=5g7sin⁡βx−cvx; y˙=vy; v˙y=5g7sin⁡βy−cvy

I=2mR25; g1+I/(mR2)=5g7; g=9.81ms2; c=0.15s−1

실험 범위와 단위

균질 구가 미끄럼 없이 구릅니다. βx, βy는 각 축의 내리막 기울기이며 양의 기울기는 양의 가속도입니다.

두 축 분리 근사: 각 축 sin⁡ 비선형은 유지하며 복합 회전 교차항·판 회전 관성력·미끄럼은 생략합니다.

이상적 내부 기울기 서보를 가정합니다. 외부 PD 제어기의 D항은 측정 위치의 변화율인 속도를 사용하며, 각 축의 이득은 독립적으로 조절합니다.

공 중심의 이동 범위는 x, y 각 축에서 ±0.30 m입니다. 경계에 도달하면 실험이 정지하며, 초기화해야 다시 실행할 수 있습니다. 벽에서 튕기는 운동은 모델링하지 않습니다.

최대 5 ms 간격마다 기울기를 일정하게 유지하며 RK4로 적분합니다. 속도 감쇠 계수는 0.15s−1입니다. 외란은 vx에 +Δv, vy에 −Δv입니다.

고정 계산 간격 0.005 s. 숨겨진 탭은 일시정지합니다.

  • 목표 x: -0.2 … 0.2 m
  • 목표 y: -0.2 … 0.2 m
  • x 위치 이득: 0 … 2 rad/m
  • x 속도 이득: 0 … 1.5 rad·s/m
  • y 위치 이득: 0 … 2 rad/m
  • y 속도 이득: 0 … 1.5 rad·s/m
  • 기울기 한계: 0.02 … 0.3 rad
  • 속도 외란: 0.05 … 0.5 m/s
