제어 구조

그림에 초점을 맞춘 뒤 방향키로 좌우로 스크롤하세요.

모델·제어식·단위·실험 범위

모델과 제어식

βx=clamp(kpx(xr−x)−kdx vx,−βmax,+βmax); βy=clamp(kpy(yr−y)−kdy vy,−βmax,+βmax)

ẋ=vx; v̇x=(5g/7)sinβx−c vx; ẏ=vy; v̇y=(5g/7)sinβy−c vy

I=2mR²/5; g/(1+I/(mR²))=5g/7; g=9.81 m/s²; c=0.15 s⁻¹

실험 범위와 단위

균질 구가 미끄럼 없이 구릅니다. βx, βy는 각 축의 내리막 기울기이며 양의 기울기는 양의 가속도입니다.

두 축 분리 근사: 각 축 sin 비선형은 유지하며 복합 회전 교차항·판 회전 관성력·미끄럼은 생략합니다.

이상적 내부 기울기 서보를 가정합니다. 외부 PD 제어기의 D항은 측정 위치의 변화율인 속도를 사용하며, 각 축의 이득은 독립적으로 조절합니다.

공 중심의 이동 범위는 x, y 각 축에서 ±0.30 m입니다. 경계에 도달하면 실험이 정지하며, 초기화해야 다시 실행할 수 있습니다. 벽에서 튕기는 운동은 모델링하지 않습니다.

최대 5 ms 간격마다 기울기를 일정하게 유지하며 RK4로 적분합니다. 속도 감쇠 계수는 0.15 s⁻¹입니다. 외란은 vx에 +Δv, vy에 −Δv입니다.

고정 계산 간격 0.005 s. 숨겨진 탭은 일시정지합니다.

  • 목표 x: -0.2 … 0.2 m
  • 목표 y: -0.2 … 0.2 m
  • x 위치 이득: 0 … 2 rad/m
  • x 속도 이득: 0 … 1.5 rad·s/m
  • y 위치 이득: 0 … 2 rad/m
  • y 속도 이득: 0 … 1.5 rad·s/m
  • 기울기 한계: 0.02 … 0.3 rad
  • 속도 외란: 0.05 … 0.5 m/s
