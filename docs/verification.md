# 검증 범위

## 실제 실행 결과

- `npm test`: 18개 통과 (물리·카탈로그·이동 거리 계산)
- `npx playwright test tests/browser.spec.js --workers=1`: 7개 통과 (로컬)
- `python3 tests/independent_reference.py`: 통과. 기본 모터 PD 응답을 SciPy 연속시간 기준과 비교, 최대 절대 차이 약 0.015616 rad. 제어 주기 0.005 s의 표본 제어이므로 완전 일치는 요구하지 않음.
- 대시보드와 세 실험의 데스크톱 화면, 모바일 대시보드와 볼 앤 빔 화면 육안 확인. 모바일 가로 넘침은 네 경로 자동 확인.
- 설치 없는 정적 구성. 사용자 입력 저장·전송 및 계정·다운로드 기능 없음.

## 검사한 상호작용

검색과 빈 검색 결과, 분야·실행 가능 필터 조합, 첫 화면 일시정지, 실행·정지·초기화, 키보드 목표 조절, 외란, 레일 이탈 시 중단 및 초기화 후 재실행.

## 모델 제한

브라우저 모델은 교육용 독립 구현이며 MATLAB 프로젝트와 동일한 모델/결과를 보장하지 않습니다. 물리 시험은 이상화한 모델의 일관성과 예상 거동에 대한 검증이며, 실제 장치 검증이 아닙니다.
