# 구현 결정

## 사용 목적

제어 동아리 신입·기존 부원과 강의 참여자에게 도구 설치 없이 제어 경험을 제공한다. 특정 동아리·연구실 브랜드를 노출하지 않고 Control Simulators로 운영한다. 페이지 제목·헤더·푸터에서 ICaR 표기를 사용하지 않는다. 호스팅 주소는 유지한다.

- 저장소: ICaRLaboratory/simulators
- 경로: /simulators/ (복수)
- 체험 수준: 기존 연구실 Research 탭 정도의 가벼운 조작·애니메이션·그래프
- 다운로드, 계정, 과제 제출, 결과 저장은 범위에서 제외
- 원본 MATLAB 프로젝트는 참고 주제·자료이며 웹에서 원본 .slx/.mlx를 실행하지 않음
- 1차 실제 구현: 크루즈 컨트롤, DC 모터, 볼 앤 빔
- 전체 프로젝트 목록을 대시보드에 포함하고 나머지는 명확히 준비 중 표시
- 신규 제작물만 이 공개 저장소에 게시. 학생 개인정보가 포함된 원본 PPTX는 업로드하지 않음
- 연구실 원본 홈페이지 수정은 별도 작업
- 화면 테마는 연구실 홈페이지의 흑백 색상·Pretendard 글꼴·검정 헤더/푸터·카드/버튼 스타일에 맞추되 연구실 이름이나 로고는 노출하지 않음
- 재구성/이식 여부 및 데이터 저장 여부에 관한 부가 문구는 화면에서 제외하고, 관련 MATLAB 프로젝트 링크로 자료를 안내

## 상호작용 원칙

처음에는 정지 상태로 표시하고 학생이 시작한다. 목표·게인 변경, 외란 주기, 일시정지, 초기화로 실험한다. 공의 레일 이탈 등 실패는 상태로 표시하고 초기화를 안내한다. 물리 계산은 화면 프레임 속도와 분리한다. 외부 탭으로 이동하면 일시정지한다.

## 제어 루프 표시

각 실행 가능한 실험에 목표·오차·제어기·입력 제한·제어 대상·출력 피드백 구조를 표시한다. 구조도는 실제 구현을 따른다: P/I는 오차에, D는 측정 출력의 변화율에 적용한다. 차량과 모터의 부하 외란은 제어 대상 입력에서 빼고, 볼 앤 빔의 외란은 속도에 순간적으로 더한다. 볼 앤 빔은 sin(θ)를 포함한 비선형 식을 사용한다. 구조도 추가로 물리 계산을 바꾸지 않는다.

## 정확성

각 실험에 방정식·단위·단순화·입력 제한을 표시한다. 시각 효과를 물리 모델의 증거로 사용하지 않는다. 독립 수치해석 및 단위 테스트로 모델 응답을 확인하고 브라우저 테스트로 조작·반응형을 확인한다.
