# 구현 결정

## 사용 목적

제어 동아리 신입·기존 부원과 강의 참여자에게 도구 설치 없이 제어 경험을 제공한다. 특정 동아리·연구실 브랜드를 노출하지 않고 Control Simulators로 운영한다. 페이지 제목·헤더·푸터에서 ICaR 표기를 사용하지 않는다. 호스팅 주소는 유지한다.

- 저장소: ICaRLaboratory/simulators
- 경로: /simulators/ (복수)
- 체험 수준: 기존 연구실 Research 탭 정도의 가벼운 조작·애니메이션·그래프
- 다운로드, 계정, 과제 제출, 결과 저장은 범위에서 제외
- 원본 MATLAB 프로젝트는 참고 주제·자료이며 웹에서 원본 .slx/.mlx를 실행하지 않음
- 실행 가능: 크루즈 컨트롤, DC 모터, 볼 앤 빔, 도립진자
- 전체 프로젝트 목록을 대시보드에 포함하고 나머지는 명확히 준비 중 표시
- 신규 제작물만 이 공개 저장소에 게시. 학생 개인정보가 포함된 원본 PPTX는 업로드하지 않음
- 연구실 원본 홈페이지 수정은 별도 작업
- 화면 테마는 연구실 홈페이지의 흑백 색상·Pretendard 글꼴·검정 헤더/푸터·카드/버튼 스타일에 맞추되 연구실 이름이나 로고 텍스트는 노출하지 않음. 단, 운영자 승인(2026-09)으로 헤더 브랜드 옆에 연구실 심벌 이미지(assets/lab-logo.png, alt 없음)만 표시한다. ICaR 텍스트 표기는 계속 사용하지 않는다.
- 재구성/이식 여부 및 데이터 저장 여부에 관한 부가 문구는 화면에서 제외하고, 관련 MATLAB 프로젝트 링크로 자료를 안내

## 언어와 기존 실험 연결

한국어/EN 전환은 대시보드와 각 실험의 문구·상태·구조도·접근성 설명에 함께 적용한다. 명시적인 `?lang=ko|en`을 우선하며 언어 선택만 저장한다. 언어를 바꿔도 실험 상태·설정·그래프는 유지한다.

Research의 궤적 추종과 상호작용 제어는 복제하지 않고 해당 탭으로 연결한다: `research.html?sim=track|contact&lang=ko|en#interactive`. 전체 17개 중 실행 가능은 로컬 4개와 Research 2개이며 나머지 11개는 준비 중이다. Research 링크를 MATLAB 프로젝트라고 표시하지 않는다.

## 상호작용 원칙

처음에는 정지 상태로 표시하고 학생이 시작한다. 목표·게인 변경, 외란 주기, 일시정지, 초기화로 실험한다. 공의 레일 이탈 등 실패는 상태로 표시하고 초기화를 안내한다. 물리 계산은 화면 프레임 속도와 분리한다. 외부 탭으로 이동하면 일시정지한다.

## 제어 루프 표시

각 실행 가능한 실험에 목표·오차·제어기·입력 제한·제어 대상·출력 피드백 구조를 표시한다. 구조도는 실제 구현을 따른다: P/I는 오차에, D는 측정 출력의 변화율에 적용한다. 차량과 모터의 부하 외란은 제어 대상 입력에서 빼고, 볼 앤 빔의 외란은 속도에 순간적으로 더한다. 볼 앤 빔은 sin(θ)를 포함한 비선형 식을 사용한다. 구조도 추가로 물리 계산을 바꾸지 않는다.

## 도립진자

도립진자는 기존 PID 모듈을 바꾸지 않고 `pendulum-physics.js`의 비선형 카트·질점 진자와 `pendulum-app.js`의 독립 화면으로 구성한다. 상태는 `[x, v, θ, ω]`이고 θ=0은 직립, 양의 각도는 오른쪽 기울기이다. 전상태 피드백 `F = kx(x−r) + kv·v + kθ·θ + kω·ω`를 사용하며 실제 힘 u는 ±20 N으로 제한한다. 위치 오차의 부호는 기존 PID의 r−x와 다르므로 구조도에 명시한다. 스윙업은 포함하지 않는다.

M=1 kg, m=0.2 kg, l=0.5 m, b=0.1 N·s/m, g=9.81 m/s². 질량 없는 막대, 관절 마찰 없는 점질량 모델이다. 기본 이득은 직립 선형화의 극점 −1.5, −2, −2.5, −3 s⁻¹ 배치값을 반올림한 kx=1.15, kv=2.28, kθ=27.22, kω=5.59이며, SI 단위로 계산한다. 각도 표시는 rad이다.

힘을 각 계산 구간에서 유지하는 RK4를 최대 0.005 s 간격으로 수행한다. 초기 각도는 0.08 rad. 외란은 각속도 +0.5 rad/s의 순간 변화이며 지속 힘이 아니다. |x|≥2 m 또는 |θ|≥π/3이면 실패를 유지하고 초기화해야 한다. 초기화는 목표·이득을 유지한다. 위치/목표와 직립 각도 응답을 분리하여 최근 15초를 표시한다.

## 정확성

각 실험에 방정식·단위·단순화·입력 제한을 표시한다. 시각 효과를 물리 모델의 증거로 사용하지 않는다. 독립 수치해석 및 단위 테스트로 모델 응답을 확인하고 브라우저 테스트로 조작·반응형을 확인한다.
