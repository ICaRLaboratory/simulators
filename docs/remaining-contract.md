# New experiment module contract

All remaining 11 local experiments use `assets/experiment-app.js`, `assets/experiment.css`, and per-experiment `assets/models/<id>.js`. Existing four experiment implementations remain unchanged.

## Required exports

- `definition`: `{id, title:[ko,en], description:[ko,en], source:httpsURL, parameters:[{key,label:[ko,en],unit,min,max,step,default}], metrics:[{key,label:[ko,en],unit,digits}], plots:[{label:[ko,en],unit,range:[min,max],series:[{key,label:[ko,en],color,dash?:boolean}]}], loop:{reference:[ko,en],controller:[ko,en],actuator:[ko,en],plant:[ko,en],feedback:[ko,en],disturbance:[ko,en]}, equations:[string], notes:[[ko,en],...], disturbance:[ko,en]}`. Add `failureMessages:{code:[ko,en]}` if needed. Teal #087f74 actual; orange #c56b31 dashed target. At most 8 parameters and 3 plots. Values and graphs must have physical units. Exact defaults lie on min/step grid. Every graph series and metric key must appear as a finite number in observe().
- `Simulation`: constructor builds independent `params` from definition defaults and `state` with `{t:0,failed:false,failure:''}` plus physical states. Methods `step(dt)`, `reset()`, `disturb()`, `observe()`. `step` requires finite dt in (0,1], subdivides <=0.005 s; finite params checked BEFORE mutating state. Full params identity retained on reset; failure latched until reset. `disturb` no-op when failed. `observe()` returns a NEW object `{t,...numericPlotAndMetricKeys}` including target values from params, not a mutable state reference. Integration/rendering separate. Optional state.complete boolean for parking (runtime pauses at completion); reset clears it.
- `draw(ctx,state,params,width,height,language)`: render schematic only; never advance/mutate physics. Canvas is cleared and DPR transformed by runtime. Language 'ko'|'en'. Numeric/text annotations >=12px Pretendard; clear target/actual distinction, dimensional legends. Use projected view or explicit schematic for 3D models; do not call independent scalar oscillators a coupled robot/Furuta model.

## Page/runtime responsibilities

Runtime imports module based on HTML `body[data-experiment]` from fixed allowlist. Model authors OWN ONLY assigned `assets/models/<id>.js` and `tests/<id>.test.js`; no common UI/catalog/shared CSS edits. Parent owns documentation/catalog and static page generation. Runtime/UI author owns `assets/experiment-app.js`, `assets/experiment.css`, `scripts/build-experiment-pages.mjs` and `tests/remaining-browser.spec.js` and generated 11 `<id>/index.html`. Generator imports each definition and builds full static Korean HTML model/diagram/project content (accessible without JS), with bilingual data attributes and original Korean capture. Do not translate/replace input containers or reset physics on language switch. Shared i18n handles header/query/persistence; own model-local strings/data-en may extend it. Generate only existing contracted model files, fail on missing in final run. HTML escapes content before serialization. No physics on server, no dependencies at runtime beyond local ESM.

Initial paused; fixed .005 simulation step and bounded animation catch-up, hidden-tab pause, reduced-motion rendering, resize redraw, rolling15s plots, reset settings preserved, start/pause/disturb/reset controls. Runtime stores sample history independently and copies observe(), stops on failed or complete, does not save data. Only language localStorage. Show meaningful localized failure code from failureMessages or fallback; failed disables start/disturb. Generic SVG must include model-specific loop names and clear feedback arrow and disturbance entering correct place; exact controller equations in collapsed details. For multiloop models notes explain inner/outer loops. User-facing headings Control Simulators only, existing neutral theme, fonts, chips. Source links labeled 관련 MATLAB 프로젝트, no port/disclaimer filler.
