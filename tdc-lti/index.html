2차 LTI 시스템의 시간 지연 제어(TDC)

과거의 가속도와 실제 적용 입력으로 현재의 미지 동역학을 추정합니다. 외란이 바뀐 직후 추정값이 따라오는 시간을 확인하세요.

2차 시스템 설정

G(s)=1s2+s+1

공통 조건: y(0)=v(0)=0, r=1, 20초, 측정 잡음 없음. 구동기 입력 u의 한계는 ±4입니다. 플랜트 입력은 u+d이며, 입력 외란 d는 4초부터 0입니다. 제어기: 이산시간, Ts=0.02초.

실제 F는 시뮬레이터만 아는 진단값입니다. 제어기에는 과거 측정으로 구한 추정값만 전달됩니다.

입력 외란을 0.8로 설정하세요. 4초에 외란을 가한 뒤 몇 샘플이 지나야 추정값에 반영되나요? 추정 지연 ℓ을 늘려 비교하세요.

적용 입력 u
종료 시 출력 y—

모델·제어식·가정

G(s)=bs2+a1s+a0, b=Kωn2, a1=2ζωn, a0=ωn2

y¨=−a0y−a1y˙+b(u+d) =F+b0u

F=−a0y−a1y˙+(b−b0)u+bd

a‾[k]=v[k+1]−v[k]Ts, Fˆ[k]=a‾[k−ℓ]−b0u[k−ℓ]

r=1, u=clip⁡(6.25(r−y)−5y˙−Fˆb0,−4,4)

출력과 속도는 0에서 시작하고 목표값 r은 첫 샘플부터 1입니다. 제어기는 목표값을 미분하지 않고 측정 속도 y˙를 사용합니다. b0는 설정한 비율에 실제 입력 계수 b를 곱한 교육용 보정값입니다. 그래프의 실제 F는 각 입력 유지 구간의 평균입니다. 추정에는 같은 구간의 평균 가속도와 실제 구동기 입력 u를 사용하며, 외란 d는 측정하지 않습니다. 외란의 기본값은 0이며 4초부터 u에 더해집니다. ℓ은 구동기 통신 지연이 아니라 추정에 쓰는 과거 샘플의 지연입니다. 이력이 없는 동안 추정값은 0입니다.

같은 시스템으로 다른 제어 실험: PID → · MPC → · DDC → · SMC →
