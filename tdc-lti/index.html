2차 LTI 시스템의 시간 지연 제어(TDC)

과거의 가속도와 실제 적용 입력으로 현재의 미지 동역학을 추정합니다. 외란이 바뀐 직후 추정값이 따라오는 시간을 확인하세요.

2차 시스템 설정

G(s) = 1 / (s² + s + 1)

시간지연 제어 추종 응답

출력 y목표 r

제어기 설정

1
1
0.8

미지 동역학과 시간지연 추정

실제 F지연 추정 F̂

실제 F는 시뮬레이터만 아는 진단값입니다. 제어기에는 과거 측정으로 구한 추정값만 전달됩니다.

실험해 보기

지연 샘플 수를 늘려 보세요. 4초에 외란이 바뀔 때 실제 F와 추정값이 갈라지는 구간을 보고, 입력 이득 비를 바꿔 다시 확인하세요.

적용 제어입력

적용 입력 u
종료 시 출력 y—
최대 적용 |u|—
추정 지연 시간—
모델·제어식·가정

G(s) = b / (s² + a₁s + a₀),　b = Kωₙ²,　a₁ = 2ζωₙ,　a₀ = ωₙ²

ÿ = F + b₀u

ā[k] = (v[k+1] − v[k]) / Tₛ,　F̂[k] = ā[k−ℓ] − b₀u[k−ℓ]

u = clip((r̈ + 6.25(r − y) + 5(ṙ − ẏ) − F̂)/b₀, −4, 4)

목표는 3초 동안 0에서 1까지 매끄럽게 이동한 뒤 유지됩니다. F는 각 입력 유지 구간에서의 평균값이며, b₀는 조절한 비율에 실제 입력 계수 b를 곱한 교육용 보정값입니다. 초기에는 지연 이력이 없으므로 추정값을 0으로 둡니다. 가속도와 입력은 같은 시점의 값으로 짝지으며, 입력에는 포화 전 명령이 아닌 실제 적용값을 사용합니다. 조절하는 지연은 추정에 쓰는 이력 길이이지 구동기 통신 지연이 아닙니다.

같은 시스템으로 다른 제어 실험: PID → · MPC → · DeePC → · SMC →
