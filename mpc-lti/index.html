2차 LTI 시스템의 MPC 제어

얼마나 먼 미래까지 예측해야 할까요? 예측 구간을 바꾸고, 같은 입력 한계에서 MPC와 PID의 응답을 비교하세요.

적용 입력과 예측 입력

비교해 보기

  1. 예측 구간을 줄여 첫 MPC 입력과 출력이 목표값 1에 접근하는 속도를 비교하세요.
  2. 가중치 λ를 높여 보세요. 입력 변화를 더 억제하면 계단 모양의 입력은 어떻게 바뀌나요?
  3. 입력 한계를 0.5로 낮춰 보세요. 두 제어기 중 어느 쪽이 출력 1을 유지할 수 있을까요?

모델·목적함수·비교 조건

G(s) = Kωₙ² / (s² + 2ζωₙs + ωₙ²)

J = Σⱼ₌₁ᴺ (ŷⱼ − 1)² + λ [(u₀ − u₋₁)² + (u₁ − u₀)²]

두 제어기는 정지 상태에서 같은 단위 계단 입력을 20초간 추종합니다. 샘플 주기는 0.2초이며, 구간마다 입력을 일정하게 유지한 정확 이산 모델을 사용합니다. 위치와 속도를 안다고 가정하고 잡음·외란·모델 오차는 제외했습니다.

MPC는 매 시점에서 입력 한계를 만족하는 두 값, 즉 다음 한 구간의 입력과 그 뒤 예측 구간 끝까지 유지할 입력을 선택합니다. 위 목적함수를 최소화한 뒤 첫 입력만 적용합니다. u₋₁은 직전에 적용한 입력이며 초깃값은 0입니다. 종단 비용과 종단 제약은 없습니다.

비교용 PID는 Kp = 4, Ki = 2, Kd = 2이며, 측정 속도에 미분항을 적용하고 조건부 적분으로 포화 시 적분 누적을 제한합니다. 연속시간 PID 단독 실험과 달리 여기서는 MPC와 같은 샘플 주기와 입력 한계를 적용합니다.
