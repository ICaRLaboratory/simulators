2차 LTI 시스템의 MPC 제어

예측 구간과 입력 한계를 바꾸며 MPC가 다음 입력을 선택하고 목표값을 추종하는 과정을 살펴보세요.

G(s) = 1 / (s² + s + 1)

점선은 선택한 시점의 예측입니다. MPC는 첫 입력만 적용하고 0.2초 뒤에 다시 계획합니다.

적용 입력과 예측 입력

관찰 포인트

  1. 예측 구간을 줄여 첫 MPC 입력과 출력이 목표값 1에 접근하는 속도를 비교하세요.
  2. 가중치 λ를 높여 보세요. 입력 변화를 더 억제하면 계단 모양의 입력은 어떻게 바뀌나요?
  3. 입력 한계를 0.5로 낮춰 보세요. 현재 시스템 이득에서 MPC가 출력 1을 유지할 수 있을까요?

모델·목적함수·가정

G(s) = Kωₙ² / (s² + 2ζωₙs + ωₙ²)

J = Σⱼ₌₁ᴺ (ŷⱼ − 1)² + λ [(u₀ − u₋₁)² + (u₁ − u₀)²]

시스템은 정지 상태에서 시작하고 MPC는 단위 계단 입력을 20초간 추종합니다. 샘플 주기는 0.2초이며, 구간마다 입력을 일정하게 유지한 정확 이산 모델을 사용합니다. 위치와 속도는 잡음 없이 측정합니다. MPC는 외란이 없는 모델로 예측하며, 실제 플랜트에만 u + d가 작용합니다. 계획 입력 한계는 고정된 구동기 한계 ±4보다 좁게 설정할 수 있습니다.

MPC는 매 시점에서 입력 한계를 만족하는 두 값, 즉 다음 한 구간의 입력과 그 뒤 예측 구간 끝까지 유지할 입력을 선택합니다. 위 목적함수를 최소화한 뒤 첫 입력만 적용합니다. u₋₁은 직전에 적용한 입력이며 초깃값은 0입니다. 종단 비용과 종단 제약은 없습니다.
