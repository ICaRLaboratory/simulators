2차 LTI 시스템의 슬라이딩 모드 제어(SMC)

슬라이딩 면에 접근하는 오차 궤적과 제어입력을 살펴봅니다. 경계층을 넓히면 입력의 떨림과 추종 오차는 어떻게 달라질까요?

2차 시스템 설정

G(s) = 1 / (s² + s + 1)

슬라이딩 모드 추종 응답

출력 y목표 r

제어기 설정

1.5
2
0.1
0.8

오차 위상평면

오차 궤적슬라이딩 면 s = 0

가로축은 오차 e = y − 1, 세로축은 오차 변화율입니다. 점선은 s = 0인 직선입니다.

실험해 보기

φ를 0으로 두고 4초 부근의 입력을 확대하세요. 경계층을 넓힌 뒤 입력 전환과 외란 이후의 오차가 어떻게 변하는지 확인하세요.

적용 입력 u
종료 시 출력 y—

모델·제어식·가정

G(s) = b / (s² + a₁s + a₀),　b = Kωₙ²,　a₁ = 2ζωₙ,　a₀ = ωₙ²

e = y − 1,　s = ẏ + λe

b u* = a₀y + (a₁ − λ)ẏ − η sat(s/φ)

u = clip(u*, −4, 4),　ÿ = −a₀y − a₁ẏ + bu + d

φ = 0이면 부호 함수를 사용합니다. 제어기는 공칭 동역학을 상쇄하지만 외란을 미리 알지는 못합니다. 입력 포화와 이산 샘플링이 있으므로 이상적인 연속시간 도달을 보장하는 실험은 아닙니다.

같은 시스템으로 다른 제어 실험: PID → · MPC → · DeePC → · TDC →
