2차 LTI 시스템의 슬라이딩 모드 제어(SMC)

슬라이딩 면에 접근하는 오차 궤적과 제어입력을 살펴봅니다. 경계층을 넓히면 입력의 떨림과 추종 오차는 어떻게 달라질까요?

2차 시스템 설정

G(s)=1s2+s+1

공통 조건: y(0)=v(0)=0, r=1, 20초, 측정 잡음 없음. 구동기 입력 u의 한계는 ±4입니다. 플랜트 입력은 u+d이며, 입력 외란 d는 4초부터 0입니다. 제어기: 이산시간, Ts=0.02초.

슬라이딩 모드 추종 응답

출력 y목표 r

제어기 설정

1.5

오차 위상평면

오차 궤적슬라이딩 면 s=0

가로축은 오차 e=y−1, 세로축은 오차 변화율입니다. 점선은 s=0인 직선입니다.

실험해 보기

입력 외란을 0.8로 설정하고 φ=0에서 4초 부근의 제어입력을 확대하세요. 경계층을 넓히면 입력 전환과 외란 이후의 정상상태 오차는 어떻게 달라지나요?

적용 제어입력

적용 입력 u
종료 시 출력 y—
최대 적용 |u|—
종료 시 슬라이딩 변수 s—
모델·제어식·가정

G(s)=bs2+a1s+a0, b=Kωn2, a1=2ζωn, a0=ωn2

e=y−1, s=y˙+λe

bu∗=a0y+(a1−λ)y˙ −ηsat⁡(sφ)

u=clip⁡(u∗,−4,4), y¨=−a0y−a1y˙+b(u+d)

입력 외란 d의 기본값은 0입니다. 4초부터 포화된 제어입력 u에 설정한 외란이 더해집니다. 포화가 없을 때 샘플 시점의 도달식은 s˙=−ηsat⁡(sφ)+bd이며, φ=0이면 부호 함수를 사용합니다. 제어기는 d를 측정하지 않습니다. 입력 포화와 이산 샘플링 때문에 이상적인 연속시간 도달은 보장되지 않습니다.
