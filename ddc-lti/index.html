2차 LTI 시스템의 데이터 기반 제어(DDC)

기록한 입력·상태 데이터로 상태 피드백 이득 K를 구합니다. 감쇠율을 높이면 단위 계단응답과 필요한 제어입력이 어떻게 달라질까요?

2차 시스템 설정

G(s) = 1 / (s² + s + 1)

데이터 기반 상태 피드백 단위 계단응답

출력 y목표 r

제어기 설정

1

이득 설계에 사용한 입력·상태 기록

기록 입력 u측정 위치 y측정 속도 v

정지 상태에서 입력 u를 가하고 위치 y와 속도 v를 측정한 별도의 실험 기록입니다. 감쇠율은 이 기록에서 설계하는 이득을 바꾸지만 기록 자체는 바꾸지 않습니다.

실험해 보기

감쇠율을 바꾸고 피드백 이득과 최대 입력을 비교하세요. 수집 입력을 0으로 바꾸면 기록 길이는 같아도 이득을 구할 수 없는 이유는 무엇인가요?

모델·제어식·가정

G(s) = b / (s² + a₁s + a₀),　b = K_DCωₙ²,　a₁ = 2ζωₙ,　a₀ = ωₙ²

x = [y, v]ᵀ,　v = ẏ

P = X₀Q = Pᵀ,　[P, X₁Q; (X₁Q)ᵀ, P] ≻ 0

K = U₀Q P⁻¹,　A_cl = X₁Q P⁻¹,　ρ(A_cl) < 1

x* = [1, 0]ᵀ,　u = clip(u* + K(x − x*), −4, 4)

De Persis–Tesi의 안정화 조건은 무잡음 이산시간 선형 시스템의 입력과 전체 상태 기록을 사용합니다. X₀와 X₁의 대응하는 열은 한 샘플 간격의 연속 상태이며, U₀에는 그 사이에 적용한 입력을 둡니다. 이 실험은 [U₀; X₀]의 행 랭크가 3인지 확인한 뒤 목표 극점 exp(−αTₛ), exp(−2αTₛ)에 맞춰 Q를 구성하고 위 행렬의 양의 정부호성을 확인합니다. ρ는 폐루프 극점의 최대 절댓값입니다.

단위 계단 추종은 논문의 원점 안정화 결과를 목표 평형점으로 옮긴 교육용 예입니다. 외란 없는 별도 기록에서 평형 입력 u*와 이득 K를 구합니다. 정지 상태에서 첫 샘플부터 r = 1을 주며 각 명령은 0.2초 동안 유지합니다. 안정성 조건과 극점은 포화되지 않은 공칭 폐루프에 대한 것으로, 입력 포화 또는 지속 외란이 있을 때 오차가 0이 됨을 보장하지 않습니다.

같은 시스템으로 다른 제어 실험: PID → · MPC → · SMC → · TDC →
